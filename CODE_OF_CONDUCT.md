# Code of Conduct / ميثاق السلوك

We follow the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good intent, and critique ideas — never people.
كن محترمًا، وافترض حسن النية، وانتقد الأفكار لا الأشخاص.

Report unacceptable behaviour by opening a private security advisory or contacting the maintainer on GitHub.
