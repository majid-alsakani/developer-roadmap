# مصادر المنهج التعليمي

هذا الملف يوثق مصادر البداية التي بُني عليها توسيع تجربة التعلم. تُفضّل الوثائق الأصلية والدورات الرسمية، ولا يُضاف فيديو أو رابط إلا بعد ربطه بمعرّف موضوع حقيقي والتحقق من عنوانه ومصدره.

| المجال | المصدر | الاستخدام |
|---|---|---|
| تطوير الويب | [MDN Learn Web Development](https://developer.mozilla.org/en-US/docs/Learn_web_development) | منهج متدرج من وحدات البداية إلى الوحدات الأساسية، مع اختبارات مهارة وتحديات ومصادر فيديو مكملة. |
| Python | [Python Tutorial](https://docs.python.org/3/tutorial/) | أساسيات المفسر، الصياغة، التحكم، هياكل البيانات، الوحدات، الملفات، الاستثناءات، الأصناف، البيئات والحزم. |
| Backend/API | [FastAPI Tutorial](https://fastapi.tiangolo.com/tutorial/) | بناء API خطوة بخطوة، التحقق، الاعتماديات، الأمان، قواعد البيانات، الاختبار، النشر والحاويات. |
| AI/ML | [Google Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course) | فيديوهات ورسومات تفاعلية وتمارين عملية في النماذج والبيانات والشبكات العصبية وLLMs والإنتاج والإنصاف. |
| DevOps/Kubernetes | [CNCF Training Courses](https://www.cncf.io/training/courses/) و[Introduction to Kubernetes](https://training.linuxfoundation.org/training/introduction-to-kubernetes/) | دورات Cloud Native موثوقة، مع مسار مجاني تمهيدي لـ Kubernetes ومختبرات وتطبيقات عملية. |
| Android | [Android Basics with Compose](https://developer.android.com/courses/android-basics-compose/course) و[Android Developers على YouTube](https://www.youtube.com/user/androiddevelopers) | دورة رسمية تجمع الفيديوهات وCodelabs والاختبارات في Kotlin وCompose والبنية والشبكة والتخزين. |
| React | [React Tutorial for Beginners](https://www.youtube.com/watch?v=SqcY0GlETPk) | فيديو مكمل لموضوع React بعد التحقق من عنوانه وقناته؛ لا يحل محل التطبيق والاختبار. |

## قاعدة الجودة

كل موضوع جديد يجب أن يمتلك هدفًا تعليميًا، متطلبات سابقة واضحة، شرحًا عربيًا وإنجليزيًا، مصدرًا موثوقًا، تمرينًا قابلًا للتنفيذ، واختبارًا تمت مراجعته. الفيديو مكمل وليس دليل إنجاز؛ لا يصبح الموضوع مكتملًا إلا بعد تغيير حالة الموضوع وتنفيذ تمرين أو مشروع مناسب.
