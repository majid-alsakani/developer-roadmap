1. Python — التزامن وحدود الموارد

الدالة غير المتزامنة لا تعني تنفيذًا متوازيًا للمعالج. عند await يمكن للحلقة تشغيل عمل آخر أثناء انتظار الإدخال والإخراج. العمليات الحسابية الطويلة تحجب الحلقة؛ قِسها وانقلها إلى عمليات مستقلة عند الحاجة. تشغيل آلاف المهام دفعة واحدة قد يستنزف الذاكرة أو الاتصالات؛ ضع حدًا للتزامن وموعدًا نهائيًا وانتبه للإلغاء.

Async concurrency overlaps waiting, not CPU work. Bound concurrency, use deadlines and propagate cancellation. A semaphore limits active work, not queued tasks; use a bounded queue for very large inputs.

import asyncio

async def run_batch():
    gate = asyncio.Semaphore(3)
    async def work(i):
        async with gate:
            async with asyncio.timeout(1):
                await asyncio.sleep(0.05)
                return i * 2
    return await asyncio.gather(*(work(i) for i in range(12)))

print(asyncio.run(run_batch()))  # Python 3.11+
  1. شغّل المثال ثم سجّل العدد الأقصى للأعمال النشطة.
  2. اختبر حدًا مقداره 3؛ أدخل تأخيرًا يتجاوز الموعد وتحقق من TimeoutError.
  3. أضف اختبار إلغاء وتأكد أن الموارد تُحرر، ثم قارن بتنفيذ تسلسلي.

دليل التسليم: الاختبارات تثبت عدم تجاوز 3 أعمال نشطة، وتوثق الفشل عند انتهاء المهلة؛ لا تدّعِ أرقام إنتاج من sleep.

Deliver tests for concurrency ≤3, timeout and cancellation cleanup, plus a measured sequential comparison.

2. AI Engineer — تقييم الوكيل قبل توسيع الصلاحيات

الإجابة المقنعة قد تكون خاطئة. ابنِ مجموعة أمثلة بإجابات مرجعية، وافصل تطوير المطالبات عن مجموعة الاختبار. اعتبر محتوى الويب نتائج غير موثوقة، لا تعليمات. افصل أدوات القراءة عن الكتابة، وتحقق من مدخلات كل أداة، واطلب موافقة بشرية للعمليات الخارجية المؤثرة.

Separate development cases from held-out evaluation. Treat retrieved text as untrusted data. Validate tool arguments and require human approval for consequential writes.

  1. أنشئ 20 حالة: إجابات عادية، معلومات ناقصة، تعارض مصادر، وحقن تعليمات.
  2. سجّل لكل حالة الإجابة المتوقعة والمصادر والأداة المسموحة قبل تشغيل الوكيل.
  3. قارن نسختين بنفس الحالات وسجل صحة الإجابة، دقة المصادر، نجاح الأداة، الزمن والتكلفة.
  4. اختبر رفض إرسال رسالة دون موافقة، وتعامل مع غياب المعلومات باعتراف صريح.

دليل التسليم: ملف حالات قابل لإعادة التشغيل، تقرير نجاح وفشل، وسجل موافقة؛ 20 حالة بداية صغيرة وليست ضمان أمان.

Deliver a replayable evaluation set, failure analysis and approval log. Report the denominator and model/version; do not tune on held-out cases.

3. DevOps — نشر قابل للتراجع

نجاح البناء لا يثبت سلامة النشر. فرّق بين liveness الذي يدل على حياة العملية وreadiness الذي يحدد قدرتها على خدمة الطلبات. استخدم أثر بناء ثابتًا يحمل معرف النسخة؛ لا تعِد البناء بين الاختبار والإنتاج. يجب اختبار التراجع قبل الحاجة إليه، مع مراعاة توافق تغييرات قاعدة البيانات.

Build once, promote the same immutable artifact. Distinguish liveness from readiness. A code rollback cannot automatically reverse destructive database migrations.

  1. اكتب مسارًا يفحص التنسيق والاختبارات ثم يبني صورة تحمل معرف commit.
  2. شغّلها في بيئة اختبار بأسرار منفصلة؛ افحص readiness قبل توجيه الزيارات.
  3. أدخل فشلًا متعمدًا في النسخة الجديدة، ثم أعد النسخة السابقة وتحقق من الاستجابة.
  4. استخدم تغييرات قاعدة بيانات توسعية متوافقة قبل إزالة الأعمدة القديمة في إصدار لاحق.

دليل التسليم: خطوات نشر وتراجع، معرف الأثر، سجل فحص جاهزية، وزمن تعافٍ مقاس في بيئة الاختبار.

Deliver a deployment/rollback runbook, artifact digest, readiness evidence and measured recovery time. Do not publish secrets or label test recovery as a production SLA.

4. Professional — قرارات هندسية وأدلة أثر

التقييم المهني يعتمد على وضوح المشكلة والمفاضلات والنتائج أكثر من عدد المستودعات. وثّق قرارًا معماريًا: السياق، البدائل، سبب الاختيار، الكلفة والمخاطر، ومتى تعيد تقييمه. عند إصلاح خلل، ابدأ باختبار يفشل على النسخة القديمة وينجح بعد الإصلاح، ثم سجّل القياس قبل وبعد على نفس المدخلات.

An architecture decision record captures context, alternatives, tradeoffs, consequences and reconsideration triggers. A regression test must fail before the fix and pass after it.

  1. اختر مشكلة واحدة في مشروع فعلي وقلّلها إلى مثال قابل لإعادة الإنتاج.
  2. اكتب اختبارًا يثبت الخلل، ثم افتح تغييرًا صغيرًا مع شرح البدائل.
  3. قارن نفس البيانات قبل وبعد، واذكر البيئة والقيود بدل عبارات التفوق العامة.
  4. اطلب مراجعة زميل؛ وثّق ما تغير بسبب المراجعة وأرفق دراسة حالة مختصرة.

دليل التسليم: اختبار تراجع، قرار معماري، طلب دمج مركز، وتقرير نتيجة يمكن لشركة التحقق منه.

Deliver a focused pull request, regression test, ADR and reproducible before/after evidence. Stars and followers are discovery signals, not engineering certification.
